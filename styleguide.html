AdventureFinder PNW · Design System

National-park poster tokens & components powering the Sunshine, Powder, and Wave finders · Built with Tailwind CSS

Themes

Every adventure shares one warm paper canvas. Each page sets data-theme on <body> to swap only its signature accent, the top rule, labels, links, and active tabs all re-color automatically.

Component · Icons (Lucide)

Line icons from Lucide. They stroke with currentColor, so they inherit the palette. Use <i data-lucide="name" class="icon"></i> and call lucide.createIcons() after render.

Using the system
<!-- 1. Load the display font + compiled stylesheet -->
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="dist/adventurefinder.css" />

<!-- 2. Pick a theme on the body -->
<body data-theme="waves">

  <!-- 3. Use component classes + token utilities -->
  <div class="panel">
    <h4>Nearest swell</h4>
    <span class="text-muted">3.2 ft @ 12s</span>
  </div>
</body>

Edit tokens in src/app.css, then rebuild with npm run build:css (or npm run watch:css while developing).
